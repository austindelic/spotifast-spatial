Spotifast Spatial 0.14.1-spatial.1 brings this experimental macOS fork up to Spotifast 0.14.1, keeping native stereo spatialization and head tracking for compatible AirPods.

**Download:** [Apple Silicon Mac DMG](https://github.com/austindelic/spotifast-spatial/releases/download/v0.14.1-spatial.1/spotifast-v0.14.1-spatial.1-macos-arm64.dmg) · [SHA-256 checksums](https://github.com/austindelic/spotifast-spatial/releases/download/v0.14.1-spatial.1/checksums.txt)

## New

- **Up to date with Spotifast 0.14.1.** Includes all 159 upstream commits since the first spatial preview's base, with the new Home sections, Listening activity, audio output picker and saved equalizer presets. By @crmne and the upstream contributors. See the [0.14.0](https://github.com/crmne/spotifast/releases/tag/v0.14.0) and [0.14.1](https://github.com/crmne/spotifast/releases/tag/v0.14.1) notes for the full upstream changes and credits.
- **Keep native macOS spatial audio and head tracking.** Local playback continues through AVFoundation on supported Macs, with Off, Fixed and Head Tracked controlled by macOS. By @austindelic. Related discussions: [#678](https://github.com/crmne/spotifast/issues/678) and [#878](https://github.com/crmne/spotifast/issues/878).

## Fixed

- **Selected audio outputs work with the new device picker.** The native backend accepts upstream's persistent device IDs as well as names saved by older builds. Explicit selections stay pinned, and System default follows macOS. By @austindelic.

## Install and try it

1. Download and open the DMG, quit any running Spotifast, then drag `Spotifast.app` into Applications. This replaces an existing Spotifast app and uses the same settings.
2. Open Spotifast and sign in. Local playback requires Spotify Premium.
3. Connect compatible AirPods, choose this computer as the playback device and start a track. Enable spatial audio or head tracking through the native macOS controls.

This preview is for Apple Silicon Macs running macOS 12.3 or newer. It spatializes Spotify's stereo audio and does not add Dolby Atmos tracks. The app is ad-hoc signed and is not notarized. If macOS blocks it, follow [Apple's instructions for opening an app from an unidentified developer](https://support.apple.com/en-us/102445) after checking that the download came from this repository.

Preview updates come from this fork and use its Apple Silicon DMGs and checksum manifests. Please report fork-specific problems in [this repository's issues](https://github.com/austindelic/spotifast-spatial/issues).
