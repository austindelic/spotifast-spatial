Spotifast Spatial 0.12.0-spatial.1 is an experimental fork of [Spotifast by @crmne](https://github.com/crmne/spotifast), with native macOS spatial audio and head tracking for compatible AirPods.

**Download:** [Apple Silicon Mac DMG](https://github.com/austindelic/spotifast-spatial/releases/download/v0.12.0-spatial.1/spotifast-v0.12.0-spatial.1-macos-arm64.dmg) · [SHA-256 checksums](https://github.com/austindelic/spotifast-spatial/releases/download/v0.12.0-spatial.1/checksums.txt)

## New

- **Use macOS spatial audio controls with local playback.** Compatible AirPods can use stereo spatialization and supported head tracking while Spotifast plays on this Mac. By @austindelic. Related upstream discussions: [#678](https://github.com/crmne/spotifast/issues/678) and [#878](https://github.com/crmne/spotifast/issues/878).
- **Keep preview updates on this fork.** This build checks this repository for future preview releases and uses its Apple Silicon downloads.

## Install and try it

1. Download and open the DMG, quit any running Spotifast, then drag `Spotifast.app` into Applications. This replaces an existing Spotifast app and uses the same settings.
2. Open Spotifast and sign in. Local playback requires Spotify Premium.
3. Connect compatible AirPods, choose this computer as the playback device and start a track. Enable spatial audio or head tracking through the native macOS controls.

The app is ad-hoc signed, not Developer ID signed or notarized. If macOS blocks it, use [Apple's instructions for opening an app from an unidentified developer](https://support.apple.com/en-us/102445) after checking that you downloaded it from this repository.

## Known limitations

- This download is for Apple Silicon Macs running macOS 12.3 or newer. Intel, Windows and Linux downloads are not included in this preview.
- The effect spatializes Spotify's stereo audio. It does not provide Dolby Atmos source tracks.
- The broader EQ/device-profile and cross-platform spatial audio proposal is not included.
- This is an unofficial preview. Please report problems in [this fork's issues](https://github.com/austindelic/spotifast-spatial/issues).
